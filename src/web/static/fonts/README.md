# Self-Hosted Fonts for AttendIQ

These variable font files are self-hosted locally in the web application to comply strictly with the application's Content Security Policy (`font-src 'self'`) without requiring any external CDNs or third-party connections.

## 1. Inter
- **File**: `inter-var.woff2`
- **Weights**: Variable font (`wght` axis 100–900)
- **Role**: Body copy, UI controls, navigation, and tabular data.
- **Creator**: Rasmus Andersson
- **Source**: Fontsource package `@fontsource/inter` / Google Fonts (SIL Open Font License 1.1)
- **License**: [OFL.txt](./OFL.txt)

## 2. Plus Jakarta Sans
- **File**: `plus-jakarta-sans-var.woff2`
- **Weights**: Variable font (`wght` axis 200–800)
- **Role**: Headings, branding marks, and KPI metric counters.
- **Creator**: Gumpita Rahayu, Tokotype
- **Source**: Fontsource package `@fontsource/plus-jakarta-sans` / Google Fonts (SIL Open Font License 1.1)
- **License**: [OFL.txt](./OFL.txt)
